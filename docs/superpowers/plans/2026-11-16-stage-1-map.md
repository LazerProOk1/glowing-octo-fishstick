# Stage 1: the world map. Implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate a world from a seed string (terrain, climate, biomes, rivers, 2000–4000 land provinces) and draw it in the browser in the spirit of the HoI4 map: painted terrain, crisp province borders without pixels, zoom and pan.

**Architecture:** Generation is pure deterministic functions in `src/sim/world/`, with no DOM and no PixiJS, running in a Web Worker. The result is 2048×1024 raster arrays plus a list of provinces. Rendering in `src/render/` turns them into textures and draws them with a single shader (terrain, water, fill, borders from a distance field) plus smoothed rivers on top.

**Tech Stack:** TypeScript 5.x (strict), Vite 6, PixiJS 8, Vitest 3, ESLint 9. Font PT Sans (OFL), CC0 terrain textures.

**Spec:** `docs/superpowers/specs/2026-11-16-settlement-strategy-design.md` (sections 5.2, 6, 7, 8 item 1, 10).

## Global Constraints

- TypeScript `strict: true`, `noUncheckedIndexedAccess: true`; `any` is forbidden.
- Code in `src/sim/**` imports nothing from `src/render/**`, `src/ui/**`, `pixi.js` and never touches the DOM. Enforced by the ESLint rule `no-restricted-imports`.
- `src/sim/**` forbids `Math.random`, `Date`, `performance.now` (ESLint rules `no-restricted-properties` / `no-restricted-globals`). All randomness goes through the `Rng` from Task 2.
- A file is no longer than ~450 lines. Longer — split it.
- All interface texts live in `src/i18n/ru.ts`, the language is Russian.
- Interface style (refined by the author 2026-11-17): restrained — dark neutral panels, 1px border, hierarchy through size and weight, one accent colour, functional labels, PT Sans font. Forbidden: ornaments and diamond dividers, letter-spaced headings, a "tree" of gradients, gold everywhere, glowing strips, poetic labels, neon, rounded gradient cards, the Inter font, emoji.
- All third-party assets live in `assets/` and are listed in `assets/CREDITS.md` with source and licence.
- Performance: 60 frames/s on a map with 4000 provinces on an ordinary laptop; medium world generation up to 8 seconds, inside the worker, the interface never freezes.
- The world is a 2048×1024 rectangle of cells without wrapping at the edges, several continents and islands.

## Review Focus

1. **Degenerate seed** (all ocean, one solid continent, empty seed `""`, Cyrillic `"Бета-7"`): a normal world is expected. A test in Task 3 runs 20 seeds, including these.
2. **Tiny islands and splinter provinces**: an island smaller than the minimum province must become one province or part of a land neighbour, but not a province of 3 cells. Test in Task 6.
3. **Province id overflow** (more than 65535 with the sea ones): generation must fail with a clear error instead of quietly corrupting the texture. Test in Task 7.
4. **Map edges and extreme zoom**: the camera cannot be moved so far that the map disappears from the screen; zoom is limited. Test in Task 9.
5. **Regenerating the same seed** in the same tab (changed the hash and came back): the result matches byte for byte, old textures are freed. Determinism test in Task 8, release check in Task 10.

  interface BiomeDef {
    id: string;                  // 'mushroom_forest', latin, snake_case, unique
    name: string;                // Russian name (becomes an i18n key in Task 13)
    kind: 'water' | 'land';
    fantasy: boolean;
    color: readonly [number, number, number];   // sRGB 0..255, HSL saturation ≤ 0.45
    detail: DetailSlotName;      // atlas slot: 'grass' | 'forest' | 'sand' | 'rock' | 'snow' | 'mud' | 'paper' | new ones
    priority: number;            // higher — checked earlier
    when: { height?: Range; temperature?: Range; moisture?: Range; arcana?: Range }; // empty = matches everything (fallback biome)
    tags?: readonly ('mountain' | 'hill' | 'deepWater' | 'shallowWater')[]; // roles the generator relies on
    modifiers?: { defense?: number; moveCost?: number }; // groundwork, not used yet
  }
  interface PackManifest { id: string; name: string; version: string; biomes: BiomeDef[]; overrides?: Record<string, Partial<Omit<BiomeDef, 'id'>>> }
  interface GenOptions { packs?: string[] /* default ['base'] */; fantasy?: boolean /* false */; disabledBiomes?: string[] }
