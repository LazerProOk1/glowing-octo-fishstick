# Этап 1: карта мира. План реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** По строке-seed генерировать мир (рельеф, климат, биомы, реки, 2000–4000 сухопутных провинций) и рисовать его в браузере в духе карты HoI4: нарисованный рельеф, ровные границы провинций без пикселей, зум и перемещение.

**Architecture:** Генерация — чистые детерминированные функции в `src/sim/world/`, без DOM и PixiJS, запускаются в Web Worker. Результат — растровые массивы 2048×1024 и список провинций. Отрисовка в `src/render/` превращает их в текстуры и рисует одним шейдером (рельеф, вода, заливка, границы по полю расстояний) плюс сглаженные реки поверх.

**Tech Stack:** TypeScript 5.x (strict), Vite 6, PixiJS 8, Vitest 3, ESLint 9. Шрифт PT Sans (OFL), текстуры рельефа CC0.

**Spec:** `docs/superpowers/specs/2026-11-16-settlement-strategy-design.md` (разделы 5.2, 6, 7, 8 п.1, 10).

## Global Constraints

- TypeScript `strict: true`, `noUncheckedIndexedAccess: true`; `any` запрещён.
- Код в `src/sim/**` не импортирует ничего из `src/render/**`, `src/ui/**`, `pixi.js` и не обращается к DOM. Проверяется правилом ESLint `no-restricted-imports`.
- В `src/sim/**` запрещены `Math.random`, `Date`, `performance.now` (правило ESLint `no-restricted-properties` / `no-restricted-globals`). Вся случайность — через `Rng` из Task 2.
- Файл не длиннее ~450 строк. Больше — делить.
- Все тексты интерфейса — в `src/i18n/ru.ts`, язык русский.
- Стиль интерфейса (уточнён автором 2026-11-17): сдержанный — тёмные нейтральные панели, рамка 1px, иерархия размером и жирностью, один акцентный цвет, функциональные подписи, шрифт PT Sans. Запрещено: орнаменты и разделители-ромбики, разрядка в заголовках, «дерево» из градиентов, золото повсюду, светящиеся полоски, поэтичные подписи, неон, градиентные карточки со скруглениями, шрифт Inter, эмодзи.
- Все сторонние ассеты лежат в `assets/` и перечислены в `assets/CREDITS.md` с источником и лицензией.
- Производительность: 60 кадров/с на карте с 4000 провинций на обычном ноутбуке; генерация мира medium — до 8 секунд, в воркере, интерфейс не замирает.
- Мир — прямоугольник 2048×1024 клеток без зацикливания по краям, несколько материков и острова.

## Review Focus

1. **Вырожденный seed** (всё океан, один сплошной материк, пустой seed `""`, кириллица `"Бета-7"`): ожидается нормальный мир. Тест в Task 3 прогоняет 20 seed, включая эти.
2. **Крошечные острова и провинции-щепки**: остров меньше минимальной провинции должен стать одной провинцией или частью соседней по суше, но не провинцией из 3 клеток. Тест в Task 6.
3. **Переполнение id провинций** (больше 65535 с морскими): генерация должна падать с понятной ошибкой, а не тихо портить текстуру. Тест в Task 7.
4. **Края карты и крайний зум**: камеру нельзя увести так, чтобы карта пропала с экрана; зум ограничен. Тест в Task 9.
5. **Повторная генерация того же seed** в той же вкладке (сменили hash и вернули): результат побайтно совпадает, старые текстуры освобождаются. Тест детерминизма в Task 8, проверка освобождения в Task 10.
