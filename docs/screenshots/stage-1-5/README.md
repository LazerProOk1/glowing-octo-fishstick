Что изменилось на картинке:
- **Берег:** подсветка и заливка провинций доходят до линии берега без ступенек — и со стороны суши, и со стороны моря.
- **Море:** цвет по настоящей глубине дна (крупные формы), узкая светлая кромка у берега, едва заметная рябь волн на близком зуме. Без ореолов вокруг островов.
- **Озёра:** отдельный тип воды, светлее и зеленее моря.
- **Морские провинции:** у берега мелкие, в открытом море крупные.
- **Реки:** сужаются к истоку, тёмная кромка, доходят до воды.
- **Джунгли:** граница больше не идёт ровной линией по широте.

Цифры (этот компьютер): генерация среднего мира 4,7–4,9 с (лимит 8 с); большого 14,6 с (лимит для него не ставили);
замер кадра 5,2 мс на общем виде и 4,3 мс на максимальном зуме (≈190–230 к/с, цель 60).

Известное: края морских провинций в открытом море слегка зубчатые (форма из генерации, известно с этапа 1);
на сиде «Бета-7» с множеством островов мелководье между ними выглядит пятнами — регулируется одним параметром
(`SEA_DEPTH_SIGMA` в `src/render/seaDepth.ts`).
